# Правила для ассистента (LifeOS Lite)

Это личная папка заметок. Главные правила ассистента — в его SOUL.md, этот файл — короткая памятка для любого агента, который откроет папку.

- Начинай с `01 Профиль.md`, дальше — `00 Главная.md` и заметка по теме.
- Всё здесь личное: не цитировать наружу, не отправлять во внешние сервисы.
- Новые заметки и записи в журналы — можно. Правка и удаление существующего текста — только после «да» владельца.
- Журналы — факты, планы — предложения. Не смешивать.
- Не выдумывать факты, даты и прогресс.
- Даты в названиях файлов: `YYYY-MM-DD — тема.md`.
