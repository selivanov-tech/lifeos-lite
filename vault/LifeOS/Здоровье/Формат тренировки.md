# Формат тренировки

Единый формат: так пишу отчёты и так ассистент пишет планы и записи. Формат можно поменять под себя — ассистент будет следовать этому файлу.

## Эталон

```
# 21 октября / ноги

**1. Присед**

* 20 кг на 12 раз /
* 40 кг на 10 раз /
* 60 кг на 8 раз //

*Заметка: запас 2–3 повтора, отдых 2–3 минуты.*

**2. Подтягивания**

* Без веса на 10 раз /
* Без веса на 8 раз /
* Без веса на 6 раз /

---
/ — 1 подход
```

## Правила

1. Заголовок: `дата / тип тренировки`. Для плана без даты: `План / ноги`.
2. Упражнение — жирная строка с номером: `**1. Присед**`. Вариант — через тире: `**2. Жим лёжа — лёгкий**`.
3. Подход: `* <вес> кг на <повторы> раз` и слэши в конце.
4. Слэши = число подходов с этим весом и повторами: `/` — один, `//` — два, `///` — три.
5. Разные повторы при одном весе — каждый подход отдельной строкой.
6. Собственный вес: `Без веса на 12 раз`. Диапазон: `10–12 раз`. Дробный вес: `42,5 кг`.
7. Заметки к упражнению — курсивом под ним.
